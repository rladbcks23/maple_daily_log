# 화면 흐름

현재 앱(`app/lib/main.dart`)의 실제 화면 구성을 기준으로 정리한다.

## 1. 전체 레이아웃

- 좌측 사이드바와 우측 메인 영역으로 구성한다.
- 사이드바 상단에는 앱 이름과 현재 선택 캐릭터 요약(또는 캐릭터 선택 유도 버튼)을 보여준다.
- 사이드바 메뉴: 대시보드, 캐릭터 선택, 스케쥴러, 파티 일정, 진행중인 이벤트, 공지사항, 이번주 썬데이, 설정.
- 메인 상단에는 현재 페이지 제목을 표시하고, 스케쥴러/이벤트/공지/썬데이 화면에는 강제 새로고침 버튼을 둔다.
- 설정 화면 헤더에는 "피드백 / 버그 제보하기" 버튼을 둔다 (다른 화면에는 없음).

## 2. 최초 실행 — 넥슨 Open API 키 입력

- 저장된 API 키가 없으면 다른 화면보다 먼저 키 입력 화면을 보여준다.
- 키를 저장하면 캐릭터 선택 화면으로 넘어간다.

## 3. 대시보드

- 선택한 모든 캐릭터의 오늘 숙제·보스 완료 현황을 한 화면에 모아 보여준다.

## 4. 캐릭터 선택

- 넥슨 계정 캐릭터 목록을 카드 형태로 보여준다.
- 각 캐릭터 카드에는 캐릭터 이미지, 캐릭터명, 월드명, 직업, 레벨을 표시한다.
- 선택된 캐릭터는 선택됨 배지를 표시하고, 순서를 옮기거나 알림 대상에서 개별적으로 뺄 수 있다.
- 선택한 캐릭터는 앱 로컬 캐시(`selectedCharacters`)에 저장한다.

## 5. 스케쥴러

- 캐릭터 하나를 골라 일간/주간 콘텐츠, 보스 콘텐츠를 확인한다.
- 보스 콘텐츠는 일간, 주간, 월간으로 나누어 보여준다.
- 완료된 항목과 미완료 항목은 배경색으로 구분한다.
- 진행 횟수나 점수가 있는 항목은 현재 값과 최대 값을 함께 표시한다 (`현재 / 최대`).

## 6. 파티 일정

- 보스 파티 일정을 등록한다 (보스, 난이도, 파티원, 요일 또는 날짜, 시각).
- 검은 마법사처럼 월간 주기인 보스는 등록 시 자동으로 "월간"으로 분류되고 요일 대신 날짜를 지정한다.
- 일정 30분 전, 일정 시각에 각각 알림을 준다. 월간 보스는 등록된 시각까지 미완료면 별도 알림도 준다.

## 7. 진행중인 이벤트 / 공지사항 / 이번주 썬데이

- 진행중인 이벤트: 썸네일, 제목, 기간을 카드로 보여준다.
- 공지사항: 전체/공지/점검/업데이트/캐시샵 탭으로 필터링한다. "전체" 탭에는 캐시샵 게시글을 포함하지 않는다.
- 이번주 썬데이: 서버 DB에 저장된 최신 썬데이 메이플 정보를 보여준다.

## 8. 설정

- 예약 알림 시간(일간/주간 알림 발송 시각), 알림 종류별 on/off(전체, 앱 시작 시, 일간, 주간, 월간, 공지/이벤트), 주간 알림 요일 선택.
- 넥슨 OpenAPI 키 변경, 앱 업데이트 확인/설치, "피드백 / 버그 제보하기".

## 9. 알림 팝업

- 메이플 런처가 꺼져 있으면 앱 자체의 항상 위 알림 창으로, 켜져 있으면 Windows 토스트로 띄운다.
- 알림 창에는 원형 아이콘, 제목, 본문, "오늘 하루 그만 보기" 스위치, "확인" 버튼 하나로 구성한다.
- Windows 토스트를 클릭하면 관련 화면(스케쥴러/공지사항/파티 일정 등)으로 이동한다.

## 10. 로그인/로그아웃

- 이 앱은 넥슨 계정 로그인을 사용하지 않는다 (API 키만 사용). 로그인/로그아웃 화면은 없다.
