# 메이플 숙제알리미

메이플스토리 캐릭터의 일간/주간/월간 숙제, 보스, 파티 일정, 공지/이벤트를 챙겨서
알려주는 Windows 데스크톱 앱입니다. 서버(Django)가 넥슨 Open API와 공지 정보를 정리해서
내려주면, 앱(Flutter)이 캐릭터별 상태를 확인하고 알림을 띄워줍니다.

- `app/` — Windows 데스크톱 앱 (Flutter)
- `server/` — API 서버 (Django, [server/README.md](server/README.md) 참고)

## 다운로드 및 설치

[GitHub Releases](https://github.com/rladbcks23/maple_daily_log/releases)에서 최신 버전을 받습니다. 파일이 두 가지입니다.

- `MapleTaskReminder-Setup-<버전>.exe`: 설치 프로그램. 실행하면 바탕화면/시작메뉴 바로가기와
  "Windows 시작 시 자동 실행" 옵션까지 설정할 수 있습니다. **일반적으로 이 파일을 권장합니다.**
- `MapleTaskReminder-<버전>-windows-x64.zip`: 압축만 풀면 바로 실행되는 휴대용 버전. 설치 없이
  쓰고 싶을 때 사용합니다.

서명되지 않은 개인 배포 프로그램이라 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다.
"추가 정보" → "실행"을 누르면 정상적으로 실행됩니다.

## 넥슨 Open API 키 발급받기

이 앱은 각자의 넥슨 Open API 키로 본인 캐릭터 정보를 조회합니다. 앱 자체에는 키가 내장되어 있지
않으므로, 처음 실행하면 키를 입력하라는 화면이 먼저 뜹니다.

1. [넥슨 오픈 API 홈페이지](https://openapi.nexon.com)에 접속해서 넥슨 계정으로 로그인합니다.
2. 안내에 따라 API 이용 신청(애플리케이션 등록)을 진행합니다. 앱 이름 등 간단한 정보 입력과
   본인 인증이 필요할 수 있습니다.
3. 신청이 완료되면 마이페이지에서 발급된 API 키를 확인할 수 있습니다. 메이플스토리 API는
   보통 신청 즉시 발급됩니다.
4. 발급된 키를 복사해서 앱의 최초 실행 화면(또는 설정 → 넥슨 OpenAPI 키)에 붙여넣습니다.

> 신청 화면 구성은 넥슨 정책에 따라 바뀔 수 있습니다. 위 절차는 큰 흐름 안내이며, 실제 화면
> 문구와는 다를 수 있습니다.

입력한 키는 PC 로컬(`%LOCALAPPDATA%\MapleTaskReminder\app_config.json`)에만 저장됩니다.
앱이 넥슨 API를 조회할 때마다 요청 헤더로 우리 서버에 전달되고, 서버는 이 키로 넥슨 API를
대신 호출할 뿐 별도로 저장하지 않습니다.

## 사용 방법

### 1. 캐릭터 선택

API 키를 입력하면 넥슨 계정에 있는 캐릭터 목록이 뜹니다. 알림을 받고 싶은 캐릭터를 선택하면
됩니다. 나중에 "캐릭터 선택" 화면에서 언제든 추가/해제할 수 있습니다.

### 2. 대시보드

선택한 캐릭터들의 오늘 숙제/보스 완료 현황을 한눈에 모아 보여줍니다.

### 3. 스케쥴러

캐릭터별 일간/주간/보스 콘텐츠의 완료 여부를 자세히 확인합니다.

### 4. 파티 일정

보스 파티 일정을 등록해두면, 일정 30분 전과 시작 시각에 알림을 줍니다. 검은 마법사처럼
월간 주기인 보스는 등록 시 자동으로 "월간"으로 분류되고, 등록해둔 날짜/시각까지 완료 기록이
없으면 별도로 알림을 줍니다.

### 5. 진행중인 이벤트 / 공지사항 / 이번주 썬데이

넥슨 공식 공지, 진행 중 이벤트, 이번 주 썬데이 메이플 정보를 모아 보여줍니다. 새 공지나
이벤트 종료는 자동으로 알림이 옵니다.

### 6. 설정

알림을 켜고 끄거나 세부 조건을 조정합니다.

- 전체 알림 on/off, 앱 시작 시 확인 여부
- 일간(오늘 미접속) / 주간(화·수 요일 지정 가능) / 월간(파티 일정 기준) 알림 on/off
- 공지/이벤트 알림 on/off
- 리마인더 확인 시각(기본 21:00)

알림 판단 기준을 자세히 보고 싶다면 [docs/알림 판단 규칙.md](docs/알림%20판단%20규칙.md)를
참고하세요.

## 알아두면 좋은 점

- 창을 닫아도 앱은 트레이로 숨겨질 뿐 완전히 종료되지 않습니다. 알림을 계속 받으려면 트레이
  아이콘에서 완전히 "종료"를 누르지 않은 상태로 켜져 있어야 합니다.
- 설정 화면의 "업데이트" 버튼을 누르면 새 버전이 있는지 확인하고, 있으면 자동으로 내려받아
  설치 후 재시작합니다.
- 메이플스토리 게임/런처가 켜져 있을 때는 알림이 Windows 토스트로, 꺼져 있을 때는 앱 자체
  오버레이 창으로 뜹니다.
