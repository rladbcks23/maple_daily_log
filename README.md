# 메이플 숙제알리미

메이플스토리 캐릭터의 일간/주간/월간 숙제, 보스, 파티 일정, 공지/이벤트를 챙겨서
알려주는 Windows 데스크톱 앱입니다. 서버가 넥슨 Open API와 공지 정보를 정리해서 내려주면,
앱이 캐릭터별 상태를 확인하고 알림을 띄워줍니다.

## 기술 스택

**앱 (`app/`)** — Windows 데스크톱

- [Dart](https://dart.dev) / [Flutter](https://flutter.dev) (Windows Desktop)
- [flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications) — Windows 토스트 알림
- [window_manager](https://pub.dev/packages/window_manager) / [tray_manager](https://pub.dev/packages/tray_manager) — 창 제어, 트레이 아이콘
- [desktop_multi_window](https://pub.dev/packages/desktop_multi_window) — 항상 위 오버레이 알림 창
- [http](https://pub.dev/packages/http) — 서버/넥슨 API 통신
- [Inno Setup 6](https://jrsoftware.org/isinfo.php) — Windows 설치 프로그램 패키징

**서버 (`server/`)** — API 서버

- [Python](https://www.python.org) / [Django](https://www.djangoproject.com) 6
- [Django REST Framework](https://www.django-rest-framework.org)
- SQLite (공지/이벤트 스냅샷 저장)
- [gunicorn](https://gunicorn.org) (WSGI)
- [requests](https://requests.readthedocs.io) (넥슨 Open API 호출)

**인프라**

- [Render](https://render.com) — 서버 호스팅
- [GitHub Actions](https://github.com/features/actions) — 공지/이벤트 DB 자동 갱신 스케줄러
- [넥슨 오픈 API](https://openapi.nexon.com) — 메이플스토리 캐릭터/스케줄러/공지 데이터

## 다운로드 및 설치

[GitHub Releases](https://github.com/rladbcks23/maple_daily_log/releases)에서 최신 버전의
`MapleTaskReminder-Setup-<버전>.exe`를 받아 실행합니다. 바탕화면/시작메뉴 바로가기와
"Windows 시작 시 자동 실행" 옵션을 설치 중에 선택할 수 있습니다. 관리자 권한 없이 현재
사용자 계정 영역에 설치됩니다.

서명되지 않은 개인 배포 프로그램이라 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다.
"추가 정보" → "실행"을 누르면 정상적으로 실행됩니다.

## 넥슨 Open API 키 발급받기

이 앱은 각자의 넥슨 Open API 키로 본인 캐릭터 정보를 조회합니다. 앱 자체에는 키가 내장되어 있지
않으므로, 처음 실행하면 키를 입력하라는 화면이 먼저 뜹니다.

1. [넥슨 오픈 API 홈페이지](https://openapi.nexon.com)에 접속해서 넥슨 계정으로 로그인합니다.
2. 안내에 따라 API 이용 신청(애플리케이션 등록)을 진행합니다. 앱 이름 등 간단한 정보 입력과
   본인 인증이 필요할 수 있습니다.
3. 신청이 완료되면 마이페이지에서 발급된 API 키를 확인할 수 있습니다. 메이플스토리 API는
   보통 신청 즉시 발급됩니다.
4. 발급된 키를 복사해서 앱의 최초 실행 화면(또는 설정 → 넥슨 OpenAPI 키)에 붙여넣습니다.

> 신청 화면 구성은 넥슨 정책에 따라 바뀔 수 있습니다. 위 절차는 큰 흐름 안내이며, 실제 화면
> 문구와는 다를 수 있습니다.

입력한 키는 PC 로컬(`%LOCALAPPDATA%\MapleTaskReminder\app_config.json`)에만 저장됩니다.
앱이 넥슨 API를 조회할 때마다 요청 헤더로 우리 서버에 전달되고, 서버는 이 키로 넥슨 API를
대신 호출할 뿐 별도 DB에 저장하지 않습니다.

## 사용설명서

### 최초 실행 — API 키 입력

앱을 처음 켜면 넥슨 Open API 키 입력 화면이 뜹니다. 위에서 발급받은 키를 붙여넣고 저장하면
다음 단계로 넘어갑니다. 입력한 키는 계속 로컬에 저장되므로 이후 실행부터는 이 화면이 뜨지
않습니다.

### 캐릭터 선택

API 키로 조회된, 넥슨 계정에 속한 모든 캐릭터 목록이 뜹니다. 캐릭터 사진, 월드명, 직업, 레벨을
보고 알림을 받고 싶은 캐릭터만 골라서 선택하면 됩니다. 여러 캐릭터를 동시에 선택할 수 있고,
언제든 다시 이 화면으로 돌아와 추가/해제할 수 있습니다.

### 대시보드

선택한 모든 캐릭터의 오늘 숙제·보스 완료 현황을 한 화면에 모아서 보여줍니다. 앱을 켰을 때
가장 먼저 "오늘 뭘 안 했는지"를 빠르게 훑어볼 수 있는 화면입니다.

### 스케쥴러

캐릭터를 하나 선택해서 일간/주간/보스 콘텐츠별 완료 여부를 자세히 확인하는 화면입니다.
보스 항목은 일간/주간/월간 주기별로 구분해서 보여줍니다.

### 파티 일정

보스 파티 일정을 등록해두는 화면입니다. 보스, 난이도, 파티원, 요일(또는 월간 보스는 날짜)과
시각을 입력해두면:

- 일정 30분 전에 한 번
- 일정 시각이 됐을 때 한 번

알림이 옵니다. 검은 마법사처럼 **월간 주기인 보스는 등록할 때 자동으로 "월간"으로 분류**되고,
요일 대신 매달 날짜를 지정합니다. 등록해둔 날짜/시각이 됐는데 아직 그 달에 완료 기록이 없으면
별도로 "이번 달 숙제가 남아 있어요" 알림도 옵니다.

### 진행중인 이벤트 / 공지사항 / 이번주 썬데이

넥슨 공식 공지, 진행 중 이벤트, 캐시샵 공지, 업데이트 소식, 이번 주 썬데이 메이플 정보를
각각 모아서 보여줍니다. 이벤트는 기간(시작일/종료일)과 함께 표시되고, 목록에 새 항목이
올라오거나 진행 중이던 이벤트가 끝나면 자동으로 알림이 옵니다.

### 설정

알림을 켜고 끄거나 세부 조건을 조정하는 화면입니다.

- **알림 ON/OFF**: 전체 알림을 한 번에 켜거나 끕니다. 끄면 아래 세부 설정은 모두 무시됩니다.
- **예약 알림 시간**: 일간/주간 알림이 발송되는 시각입니다 (기본 21:00).
- **앱 시작 시 알림**: 컴퓨터를 켤 때(앱 실행 시) 공지/이벤트 변경점, 주간/월간 콘텐츠, 당일
  파티 일정을 한 번 몰아서 확인합니다.
- **일간 알림**: 오늘 접속 기록이 없거나 일일 콘텐츠가 남아있으면 알려줍니다.
- **주간 알림**: 이번 주 완료되지 않은 주간 콘텐츠가 있으면 알려줍니다. 알림을 확인할 요일을
  직접 선택할 수 있습니다 (기본 화/수요일).
- **월간 알림**: 보스 일정에 등록된 월간 보스(검은 마법사 등)를 등록된 시간에 완료했는지
  확인해서 알려줍니다.
- **공지/이벤트 알림**: 새 공지, 이벤트, 캐시샵, 업데이트가 올라오면 알려줍니다.
- **넥슨 OpenAPI 키**: 발급받은 키를 다시 입력하거나 바꿀 수 있습니다.
- **업데이트**: 새 버전이 있는지 확인하고, 있으면 눌러서 바로 설치할 수 있습니다.

## 알아두면 좋은 점

- 창을 닫아도 앱은 트레이로 숨겨질 뿐 완전히 종료되지 않습니다. 알림을 계속 받으려면 트레이
  아이콘에서 완전히 "종료"를 누르지 않은 상태로 켜져 있어야 합니다.
- 설정 화면의 "업데이트" 버튼을 누르면 새 버전이 있는지 확인하고, 있으면 자동으로 내려받아
  설치 후 재시작합니다.
- 메이플스토리 게임/런처가 켜져 있을 때는 알림이 Windows 토스트로, 꺼져 있을 때는 앱 자체
  오버레이 창으로 뜹니다.
